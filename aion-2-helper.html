Getting started

From download to dashboard.

  1. Install the Windows app

    Download the installer and close any older Nexus window before running setup. The installer and app are named Aion 2 Nexus.

  2. Set up the tools you want

    Npcap is a separate requirement for DPS capture. Get it from the official Npcap website. You can use other session tools without capture.

  3. Open AION 2 and make it yours

    Choose your overlays, review the diagnostics and save your character setup. Supported game data appears when available.

A few useful answers

Before your next session.

Is Aion 2 Helper free?

Yes. Version 1.0.2 is available as a free Windows download. The corresponding source code is also available under GPL-3.0-or-later.

Why is the installed app called Aion 2 Nexus?

Aion 2 Helper is the name of this download page. The Windows application and installer use the existing name Aion 2 Nexus. The screenshots show that application.

How do updates work?

The app checks for a new version at startup and every six hours. You can also press Check for updates. When a release is available, review the notes, download it and confirm before setup starts. Update signatures and installer checksums are verified.

Why is a reading missing from the app?

Some measurements need Npcap, an enabled tool, a supported game client or relevant game activity. Unknown readings stay blank. Open Settings and review the built-in diagnostics for the current capture and measurement status.
